## Summary

Migrates the site from Hugo to Astro 7 while keeping the current look. The zero-base redesign will happen on top of this, so this PR is deliberately about parity: same URLs, same content, same appearance. Depends on #106 for the deploy trigger (this branch carries the same one-line change).

## What changed

- **Content is untouched.** `content/` is loaded as an Astro content collection whose id is the file path, so the 172 legacy `/YYYY/MM/DD/slug.html/` URLs keep working. `static/` moved to `public/`.
- **Markdown rendering** uses Astro 7's Sätteri pipeline with two small mdast plugins: emoji shortcodes (Hugo's `enableEmoji`) and esa-style ````go:hello.go` fences, which now get a filename label and real highlighting instead of being an unknown language. Shiki dual themes give code blocks a proper dark-mode background (the old TODO in `main.scss`).
- **Pages**: top page + `/page/N/` pagination (with `/page/1/` redirecting to `/` like Hugo's alias), article pages with TOC and related posts (shared tags), `/tags/` and `/tags/<tag>/` (Hugo rendered these blank), `/2016/`…`/2023/` year archives (Hugo had them in the sitemap as blank pages), `/feed.xml` with all 214 posts, sitemap, a real 404 page.
- **Dropped**: Facebook Like (SDK from 2016), Pocket (service shut down in 2025), `chroma.css`. X and Hatena share buttons stay.
- **Tooling**: bun for packages (`bun.lock`), mise pins `node` and `bun`, `mise run` tasks map to `bun run` scripts, deploy builds with `bun run build` and publishes `dist/`. `mise run new <slug>` is a small bun script replacing the Hugo archetype.

## Verification

Compared against a Hugo reference build of the same content (a local Python script that diffs the URL set and the `.article-body` text of every page):

- Every URL in the Hugo sitemap exists in the Astro output (tags/categories aside, which changed by design).
- All 214 article bodies match as text, except: smart quotes adjacent to Japanese characters (5 articles; Astro converts, Hugo didn't), numbered footnote back-references (2), and two og:image URLs where Hugo emitted `//images/...`.
- `astro check`: 0 errors. Browser check of top page, a 2016 article with code, and the k3s article: no console errors, highlighting/TOC/related posts/images render, GA only in production builds.

- ````math` blocks are still plain code (aliased to `latex` for highlighting); KaTeX rendering can come later (MathJaxを導入する #23).
