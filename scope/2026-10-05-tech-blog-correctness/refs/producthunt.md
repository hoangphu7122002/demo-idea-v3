# Product Hunt References: Technical Blog + Reader Feedback

Recent Product Hunt launches for tools solving collaborative technical blog editing and reader feedback workflows.

## Products

- **Brevy Beta** (https://www.producthunt.com/products/brevy-beta) — "Give feedback, Google-doc style, directly on your website." First screen shows inline comment UI integrated into web pages, similar to Google Docs comments. Team members can leave feedback directly on sites without leaving, with workflow automation to Slack/Jira.

- **Cluing** (https://www.producthunt.com/products/collabwriting) — "Where agents and humans learn, build, and ship." Demo showcases a second-brain aggregating saved content and highlights, then applying AI agents to transform that knowledge into actionable work. Most recent demo shows hosted agents autonomously handling integrations and managing tasks.

- **Flask** (https://www.producthunt.com/products/flask-6) — "Give complex creative feedback, without typing comments." First screen demonstrates a unified video collaboration platform combining screen recording, annotation, visual references, and conversation—all automatically transcribed and timestamped. Described as "Notion + Loom" for creative teams.

- **Project Feed** (https://www.producthunt.com/products/project-feed) — "Project management with built-in file review." Initial interface shows collaborative workspace with feed-style updates, visual markup tools, task organization, and approval workflows. Emphasizes commenting and feedback-to-task conversion for creative assets across images, video, PDFs, and 3D models.

- **Flowershow** (https://www.producthunt.com/products/flowershow) — "Publish your markdown as a beautiful website – in seconds." Gallery images show hosted markdown publishing without code, with import from GitHub/Obsidian/CLI and drag-and-drop. Supports blogs, docs, wikis, and knowledge bases while maintaining Markdown format without vendor lock-in.

- **HackMD** (https://www.producthunt.com/products/hackmd) — "Get everyone on the same page with Markdown." Gallery showcases real-time collaborative markdown workspace emphasizing seamless team editing. Features integrations for GitHub, Obsidian, Neovim, VSCode with lightweight design for developers.

- **OpenMarkdown** (https://www.producthunt.com/products/openmarkdown) — "A markdown editor you and your agent co-edit." Initial demo shows lightweight Tauri 2 interface with simultaneous co-editing between user and AI agents via CLI, plugins, and MCP. Users can tag tasks like `[@agent] turn these notes into a table` for real-time collaboration.
